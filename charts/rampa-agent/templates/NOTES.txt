1. Verificá que el pod está corriendo y listo (READY 1/1):

     kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }}

2. Mirá los logs. Tiene que aparecer una línea de conexión aceptada por el
   plano de control (welcome) con el nombre del cluster y de la organización:

     kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "rampa-agent.fullname" . }} -f

   Si ves "unauthorized", el token no es válido o fue rotado: generá uno nuevo
   desde la web y hacé helm upgrade con el nuevo cluster.token.
   Si ves errores de red, revisá que el cluster tenga salida HTTPS hacia
   {{ .Values.api.url }} (no hace falta abrir ningún puerto de entrada).

3. En la web de Rampa, el cluster tiene que aparecer como "online" en menos de
   un minuto. Si sigue "offline", el agente no logró conectar: los logs del
   paso 2 dicen por qué.
{{- if .Values.cluster.bootstrapToken }}

Bootstrap del token:

   Instalaste con cluster.bootstrapToken, un token de un solo uso que vence en
   2 horas. Al arrancar, el agente lo canjea contra
   {{ .Values.api.url }}/v1/agent/bootstrap por el token real del cluster y lo
   guarda en el Secret {{ .Release.Namespace }}/{{ include "rampa-agent.agentTokenSecretName" . }}
   (por eso el chart crea un Role acotado a ese Secret). Si la API todavía no
   responde, reintenta hasta 10 minutos. En los arranques siguientes lee ese
   Secret y no vuelve a canjear.

   - Si el log dice que el bootstrap token "ya se usó o venció", pedí uno nuevo
     en la web (Clusters > el cluster > Comando de instalación) y hacé
     helm upgrade con --set-string cluster.bootstrapToken=<nuevo>. Si además el
     Secret {{ include "rampa-agent.agentTokenSecretName" . }} existe con un token viejo (por ejemplo después
     de rotar el token en la web), borralo antes:
       kubectl -n {{ .Release.Namespace }} delete secret {{ include "rampa-agent.agentTokenSecretName" . }}
   - Cuando el cluster esté online podés borrar el Secret de bootstrap, ya no
     sirve para nada:
       kubectl -n {{ .Release.Namespace }} delete secret {{ include "rampa-agent.bootstrapSecretName" . }}
   - Estado estable recomendado para los próximos upgrades:
       --set cluster.existingSecret={{ include "rampa-agent.agentTokenSecretName" . }} (sin bootstrapToken)
     El agente pasa a recibir el token por variable de entorno y el chart deja
     de necesitar el Role.
{{- end }}
